Project lifecycle: mock-ups

For approval (step 1). Static drawings of the proposed screens, with Omnicontact's 16 stages and its real projects placed as the dry-run mapping would place them. Colours follow the app's tokens, light and dark; status colours stay the fixed ones.

1. Stage tracker (project page)

At the top of every project with a lifecycle: the stages grouped by phase. Done stages are green, the current one is in the brand colour, a stage the project was sent back from is amber, and an overdue current stage turns red. Clicking any stage opens its panel (below).

Opens from the tracker. The checklist, the deliverables (with versions and locks), the sign-offs, history and comments. Advance is enabled only when the exit criteria are met; otherwise it lists exactly what is missing, computed by the same rules the server enforces.
